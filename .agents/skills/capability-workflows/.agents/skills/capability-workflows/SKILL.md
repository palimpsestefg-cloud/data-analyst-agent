# Data Analyst Agent

## Overview
Conversational agent for analyzing CSV files from Google Drive.

## Features
- Load CSV from Google Drive
- Describe data structure
- Filter rows
- Calculate aggregates
- Maintain conversation state

## Security
- No arbitrary code execution
- Fixed tool set only
- Input validation
- Type checking

## Usage Examples
- "Charge le fichier https://drive.google.com/file/d/..."
- "Décris les données"
- "Filtre les ventes > 1000"
- "Moyenne des ventes par région"
