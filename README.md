# Data Analyst Agent 📊

Un agent conversationnel pour analyser vos fichiers CSV depuis Google Drive.

## 🎯 Fonctionnalités

✅ **Charger** : Importez des CSV depuis Google Drive
✅ **Décrire** : Structure, colonnes, statistiques
✅ **Filtrer** : Filtrez les lignes (>, <, ==, etc.)
✅ **Agrégats** : Moyenne, somme, compte par groupe
✅ **Mémoire** : Se souvient du fichier chargé
✅ **Sécurité** : Aucun code arbitraire

## 💬 Exemples## 🚀 Déploiement

1. Poussez ce code sur GitHub
2. Déployez sur Mistral Cloud (Managed Deployment)
3. Connectez le connecteur Google Drive MCP
4. Discutez avec votre agent !

## 📦 Structure

- `workflow.py` : Code principal
- `Dockerfile` : Configuration Docker
- `requirements.txt` : Dépendances
- `.dockerignore` : Fichiers à ignorer
